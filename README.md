## 🧪 Engineering Philosophy

I like learning by **building and troubleshooting**.

Instead of stopping at:

> "I know how Docker works."

I want to reach:

> "I can diagnose why a container failed in production."

Instead of:

> "I know AWS services."

I want to understand:

> "How do these services work together to build a reliable system?"

And instead of:

> "I can call an LLM API."

I want to build:
